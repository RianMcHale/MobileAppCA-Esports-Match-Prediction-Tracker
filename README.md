# Mobile App Development - CA1

## Esports Match Prediction Tracker

A simple Android app for viewing CS2 matches and predicting which team will win.

## Current Features

- View three sample CS2 matches.
- Tap a match to choose a predicted winner.
- Select a team before saving.
- Save one prediction per match.

## Notes

The matches are currently fixed sample data based on HLTV, not live results. Predictions are stored in memory and may be lost when the app process stops.
